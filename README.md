## ✨ Proyectos Destacados (Ver Repositorios)
Estos proyectos demuestran mi capacidad para llevar conceptos académicos complejos a soluciones funcionales:

* **[Gems Seeker: Videojuego Educativo con BST](https://github.com/valeriaflorezs/Gems_seeker)**
    * **Enfoque:** Aplicación de Estructuras de Datos.
    * **Destacado:** Implementación desde cero de un **Árbol Binario de Búsqueda (BST)** para gestionar el inventario dinámico del jugador, utilizando operaciones como sucesor, predecesor y eliminación con tres casos.
* **[Swipe & Watch: Sistema de Recomendación k-NN y Grafos](https://github.com/valeriaflorezs/Swipe-Watch)**
    * **Enfoque:** Aplicación de Machine Learning y Teoría de Grafos.
    * **Destacado:** Creación de un modelo híbrido que utiliza un Grafo Bipartito para modelar la afinidad de género y **k-NN** (Distancia Euclídea) para la clasificación y recomendación de películas.
